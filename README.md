# 🍰 Doces da Ilha

Site fictício de uma doceria desenvolvido para fins de estudo e portfólio, com o objetivo de colocar em prática conhecimentos de desenvolvimento web utilizando HTML, CSS e JavaScript.

O projeto simula a presença digital de uma doceria, permitindo visualizar o cardápio, realizar pedidos, solicitar encomendas e conhecer o programa de fidelidade e a história da marca.

## 🌐 Acesse o projeto

O site está publicado no GitHub Pages:

👉 https://camilameneses92-cloud.github.io/site-doces-da-ilha/

## 💻 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- Navegação entre as páginas do site
- Cardápio com bolos, doces e bebidas
- Página para realização de pedidos
- Cálculo do subtotal e total do pedido
- Aplicação de desconto do programa de fidelidade
- Seleção da forma de pagamento
- Cálculo de troco para pagamentos em dinheiro
- Formulário para solicitação de encomendas
- Página explicativa sobre o programa de fidelidade
- Página com informações sobre a Doces da Ilha
- Layout responsivo para diferentes tamanhos de tela

## 📄 Páginas do projeto

- **Início** — apresentação da Doces da Ilha e destaques do cardápio
- **Cardápio** — apresentação dos produtos disponíveis
- **Pedidos** — seleção de produtos e finalização do pedido
- **Encomendas** — solicitação de encomendas para eventos
- **Fidelidade** — informações sobre o programa de fidelidade
- **Sobre** — história, informações e contato da doceria

## 🎯 Objetivo do projeto

O projeto foi desenvolvido como parte do meu processo de aprendizagem em desenvolvimento web, buscando aplicar na prática conceitos de estruturação de páginas com HTML, estilização e responsividade com CSS e interatividade com JavaScript.

Durante o desenvolvimento, também foram trabalhados aspectos como organização dos arquivos do projeto, experiência de navegação, formulários e adaptação da interface para diferentes dispositivos.

## 📚 Aprendizados

Durante a construção do projeto, pude praticar e desenvolver conhecimentos relacionados a:

- Estruturação de páginas utilizando HTML semântico
- Estilização de interfaces com CSS
- Criação de layouts responsivos
- Manipulação de elementos da página com JavaScript
- Implementação de cálculos e interações no front-end
- Organização de arquivos e estrutura de um projeto web
- Publicação de um site utilizando GitHub Pages

## 📌 Observação

Este é um projeto fictício desenvolvido exclusivamente para fins de estudo e portfólio. Os produtos, valores, endereço, contatos e demais informações apresentados no site são fictícios.
